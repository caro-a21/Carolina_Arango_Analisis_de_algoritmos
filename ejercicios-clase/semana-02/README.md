# Laboratorio 02 - Configuración del entorno de trabajo

El entorno virtual se creó desde la raíz del repositorio con `python -m venv venv`.
Para activarlo en Windows se utilizó `venv\Scripts\activate`.
Se verificó que el entorno estuviera activo mediante el prefijo `(venv)` en la terminal.
Se instaló `matplotlib` utilizando `pip install matplotlib`.
Las dependencias se registraron con `pip freeze > requirements.txt`.
Para reproducir el entorno se debe crear y activar nuevamente el entorno virtual.
Después se deben instalar las dependencias con `pip install -r requirements.txt`.
Los scripts de esta semana se encuentran en la carpeta `ejercicios-clase/semana-02/`.
