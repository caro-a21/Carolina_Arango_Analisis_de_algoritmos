# Análisis de Algoritmos
Este repositorio será utilizado durante todo el semestre para organizar los trabajos de la asignatura.

Repositorio del curso de Análisis de Algoritmos. Aquí se almacenarán los ejercicios realizados durante el semestre y los informes de laboratorio.

## Estructura del repositorio

* `laboratorios/`: contiene los informes de los cinco laboratorios evaluativos.
* `ejercicios-clase/`: contiene los ejercicios realizados durante las sesiones prácticas.
* `benchmarks/`: contiene scripts para medir tiempos de ejecución y realizar gráficas.
* `.gitignore`: contiene archivos y carpetas que no deben ser registrados por Git.

## Comandos básicos

Para consultar el estado del repositorio:

```bash
git status
```

Para guardar cambios en el historial:

```bash
git add .
git commit -m "Describe el cambio realizado"
```
